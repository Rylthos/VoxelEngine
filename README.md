# VoxelEngine

A basic voxel engine

![VoxelEngine](https://github.com/user-attachments/assets/2901c72e-a9a8-467a-81b5-ceb86849f8f1)

Currently implemented with a GPU SVO and 3D simplex noise for terrain generation.
Supports loading of basic .VOX models.
Basic lighting with a single shadow ray cast to a single point in the sky
